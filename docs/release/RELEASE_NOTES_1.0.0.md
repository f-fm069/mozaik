# Mozaik 1.0.0

First public release of Mozaik, a free, open-source IPTV player for Android TV and Fire TV.

## Highlights

- Live TV with a now-and-next overview and a programme guide (EPG) timeline.
- Films and series with automatic genres, posters, descriptions and ratings (optional: bring your own free TMDB API key).
- Remote-friendly settings, colour themes with live preview.
- No account, no ads, no tracking. Your playlists and keys stay on your device.

## Your own TMDB key (optional, free)

Mozaik ships without any API keys. Live TV, films and series work without one. For posters, descriptions and ratings:

1. Create a free account at https://www.themoviedb.org.
2. Open Settings > API in your TMDB account and request an API key (v3).
3. In Mozaik, open Settings > API keys, enter the key and choose "Save and check".

## Install

1. Download `Mozaik-1.0.0.apk` from this release.
2. Verify the file (optional but recommended): the SHA-256 checksum is in `Mozaik-1.0.0.apk.sha256`.
3. On Fire TV you can use the Downloader app. On Android TV, copy the file to the device (USB or file-manager app) and open it.
4. Allow installing from unknown sources for the installing app when asked.

Mozaik does not provide any content. Add your own playlist in the app. See [DISCLAIMER.md](DISCLAIMER.md).
